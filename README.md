# CRM Система для управления клиентами

## Описание
Система для управления услугами, рекламными кампаниями, лидами и контрактами.

## Функционал
- Управление услугами (CRUD)
- Рекламные кампании со статистикой эффективности
- Учёт потенциальных клиентов (лидов)
- Управление контрактами с загрузкой документов
- Конвертация лидов в активных клиентов
- Ролевая модель пользователей (Менеджер, Директор, Администратор)
- Система авторизации

## Технологии
- **Backend:** Django 4.2.7
- **Database:** PostgreSQL 17
- **Frontend:** Bootstrap 5
- **Linting:** Pylint

## Установка и запуск

1. Установите зависимости:
   pip install -r requirements.txt

2. Создайте базу данных PostgreSQL:
   CREATE DATABASE crm_db;

3. Настройте подключение в config/settings.py (раздел DATABASES):
   NAME: crm_db
   USER: postgres
   PASSWORD: postgres
   HOST: localhost
   PORT: 5432

4. Примените миграции:
   python manage.py migrate

5. Создайте суперпользователя:
   python manage.py createsuperuser

6. Запустите сервер:
   python manage.py runserver

7. Откройте в браузере: http://127.0.0.1:8000/
